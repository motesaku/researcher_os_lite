## このプロンプトについて

上のプロンプトは、わざと **漠然** に書いてあります。

研究現場で、研究者が同僚に頼むときの口調に近いものです。
詳細な仕様（データ長、温度範囲、プロットの色、ファイル形式...）
は、AI agent が計画段階で質問してくるか、自分で補完してくるはずです。

その**埋め方こそが**、AI agent のスタイルや、AGENTS.md / CLAUDE.md・SKILL.md
の設計の良し悪しを露わにします。

### 比べてみるとよいこと

1. **ルールファイルを読まないAI agent**（=ブラウザ対話型のAI）
   に同じプロンプトを投げると、何が違うか
2. **詳細なプロンプト**（データ長、温度範囲、色、軸ラベルを全部指定）を投げた場合と、
   何が変わるか
3. **異なるAI agent**（Claude Code, Cursor, Antigravity, Codex）の Plan の違い

この3つの比較を体験することが、researcher_os_lite が
伝えたいことの全てです。

### 次のプロンプトに進むには

`figures/hello.png` が生成されたら、続けて以下のような依頼を試してください。

```
このプロットに、月の英語名（Jan, Feb...）を横軸に出す版を追加で
作ってもらえますか。元のグラフは消さずに、別ファイルとして
保存してください。
```

```
今やった処理を、再現可能なように README に追記しておいてください。
データ生成のシード、使ったライブラリ、出力ファイル名がわかるように。
```

このような「あとひとつ頼む」を重ねるうちに、AI agent との
協働のリズムが体に入ります。それが研究者OSの始まりです。
