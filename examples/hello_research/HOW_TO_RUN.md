# hello_research : 5分で動かす最小サンプル

これは researcher_os_lite を最初に体験するための、5分以内に動かせるサンプルです。

特別なデータは不要です。お手元のAI agent（Claude Code, Cursor, Antigravity, Codex のいずれか）と、Pythonが動く環境があれば動きます。

---

## 何が起きるか

このサンプルでは、以下の体験ができます。

1. **漠然な依頼** を AI agent に投げる（`PROMPT.md` の内容をコピペ）
2. AI agent が **Plan（実装計画）** を返してくる
3. 計画を読んで、修正点があれば対話で詰める
4. 承認すると、AI agent が **コードと結果** を出してくる

ここで体験するのは、コードの完成ではなく、
**「Plan を介した対話で、研究者が判断点を握る型」** です。

---

## 手順

### Step 1 : ディレクトリに入る

```bash
cd researcher_os_lite/examples/hello_research
```

### Step 2 : AI agent を起動

お使いのツールに応じて、このディレクトリで AI agent を起動してください。

- **Claude Code**：`claude` コマンドを実行
- **Cursor**：このフォルダを Cursor で開く
- **Antigravity**：このフォルダを Antigravity で開く
- **Codex (Desktop)**：このフォルダを Codex で開く

どのツールでも、上位の `AGENTS.md`（または `CLAUDE.md`）と `SKILL.md` を読み込むはずです。
これらは同じ内容のルールファイルで、ツールごとに自動認識するファイル名が違うため
両方を同梱しています。
（読まれない場合は、起動後にこれら2ファイルを最初に参照させてください）

### Step 3 : プロンプトを投げる

`PROMPT.md` の内容をコピーして、AI agent に貼り付けてください。

### Step 4 : Plan が返ってきたら 3分間レビュー

AI agent が実装計画を Markdown のリストで返してくるはずです。
**ここが最も重要なステップです**。以下の観点でレビューしてください。

- 依頼の解釈は正しいか？
- 想定リスクの列挙は妥当か？
- 自分が知っている前提が、計画に反映されているか？

不足や誤りがあれば、自然言語で AI agent に伝え、計画を更新してもらってください。

### Step 5 : 承認して実装へ

計画に納得したら、「OK、進めてください」と伝えます。
AI agent はコードを生成し、実行結果まで報告します。

`figures/hello.png` のような出力ファイルが生成されれば成功です。

## 「うまくいかなかった」とき

成功するときも失敗するときも、両方が学びになります。
詰まったポイントを、ぜひ以下に追記してリポジトリに反映してください。

### よくある詰まりどころ

- **Python環境が無い** → `python --version` で確認。3.9以上を推奨。
- **必要なライブラリが無い** → AI agent が `requirements.txt` を提案するはず。
- **AI agent がルールファイルを読まない** → 起動後に「まず `AGENTS.md`（または `CLAUDE.md`）と `SKILL.md` を読んでください」と明示的に伝える。
- **Plan を出さずにいきなり実装する** → 「Rule 1 に従って、まず計画を出してから実装してください」とルールファイルの規約を参照させる。

## このサンプルの限界

このサンプルは「型」を体験するためのものです。
実際の研究データを扱う場合、以下を意識してください。

- 自分のデータパスは絶対パスで AI agent に伝える
- 機密性のあるデータは、AI agent に渡す前に必ず確認する
- 出力されたコードは、必ず自分でも目を通す
